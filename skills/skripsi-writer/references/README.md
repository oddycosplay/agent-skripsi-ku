# Indeks Referensi Skill Skripsi Writer

Dokumen referensi dikelompokkan berdasarkan fungsinya agar mudah ditemukan. File modul lama tetap berada di folder `references/` sehingga tautan dan penggunaan yang sudah ada tidak terputus.

## Panduan inti

- [`template-unpam-4-0.md`](template-unpam-4-0.md): struktur dan format naskah berdasarkan Template UNPAM 4.0.
- [`academic-writing-antislop.md`](academic-writing-antislop.md): bahasa akademik, parafrase, sitasi, dan pemeriksaan mutu tulisan.
- [`system-design-testing.md`](system-design-testing.md): analisis, pemodelan, basis data, dan pengujian sistem.

## Modul kerja

- `skill_01_pencari_judul_filter_kaprodi.md`: kurasi judul.
- `skill_02_generator_outline_skripsi_4_0.md`: penyusunan outline.
- `skill_03_generator_bab_1_pendahuluan.md` dan `skill_04_generator_bab_2_landasan_teori.md`: Bab I dan Bab II.
- `skill_05_generator_bab_3_analisa_perancangan.md` dan `skill_06_generator_bab_4_implementasi_pengujian.md`: Bab III dan Bab IV.
- `skill_07_penentu_gap_literatur_review.md`: gap dan tinjauan literatur.
- `skill_08_simulator_dosen_penguji_sidang.md`: persiapan sidang.
- `skill_09_penunjang_bab_5_abstrak_kuesioner.md`: Bab V, abstrak, dan kuesioner.
- `skill_10_penunjang_generator_kode_diagram_uml_erd.md`: diagram UML dan ERD.

Baca modul yang relevan dengan permintaan, bukan seluruh modul sekaligus. Panduan pemeriksaan sebelum hasil diserahkan tersedia di [`checklists/skripsi-quality-checklist.md`](checklists/skripsi-quality-checklist.md).
